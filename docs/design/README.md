# ATM platform design

Source files for the architecture and UX design canvas (server architecture, application architecture, ATM customer flow, supervisor maintenance screen, central monitoring dashboard).

- `canvas.json` lists the artboards and their layout.
- Each `*.dc.html` file is one artboard and can be opened in a browser as plain HTML, though the runtime script `support.js` is not included here.
- Sample data (terminal IDs, alerts, amounts) is illustrative only.
